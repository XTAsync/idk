# Golden Compass — Web Prototype

A standalone, mobile-first interface prototype for a digital investment experience. The page explores portfolio-oriented screens, investment navigation, and a dark visual system with gold and teal accents.

## Run Locally

No package installation is required.

Open `golden-compass-v6-1.html` in a modern browser, or serve the repository locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000/golden-compass-v6-1.html`.

## Scope

This repository contains a static frontend prototype. It does not, by itself, provide a connected backend, verified market data, real payments, or brokerage execution.
